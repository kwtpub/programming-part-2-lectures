## 1. `class` и понятие класса

**`class`** — класс, в котором все компоненты являются частными (`private`) по умолчанию; по необходимости можно изменить уровень доступа. Используется для построения иерархии объектов.

Сводка по трём ключевым словам (из [лекция 1](lecture-1.md) и этой лекции):

| Ключевое слово | Доступ по умолчанию | Можно менять? | Наследование |
|---|---|---|---|
| `union` | `public` | нет | нет |
| `struct` | `public` | да | да |
| `class` | `private` | да | да |

Когда мы говорим о классах в C++, то включаем в понятие те данные и функции, которые определены внутри `union`, `struct`, `class`.

Обычно ограничения на уровень доступа касаются элементов данных: данные имеют атрибут `private`, а функции — `public`.

> Под **объектом** будем понимать **экземпляр класса**.

## 2. Пример: структура `Point` и объекты

```cpp
struct Point
{
    int x;
    int y;
};

Point APoint;              // один объект
Point BPoint[50];          // массив из 50 объектов
Point *pPoint  = &APoint;  // указатель на объект
Point *pBPoint = BPoint;   // указатель на первый элемент массива
```

## 3. Методы

Классы в C++ могут содержать как данные, так и функции (методы, функции-члены класса).

**Методы** — функции, объявленные внутри определяемого класса и непосредственно с ним связанные.

> **Данные класса** — то, что класс *знает*.
> **Методы** — то, что класс с данными *делает*.

### 3.1. Два способа включения метода в класс

Добавим классу `Point` ещё два метода.

**Способ 1 — определение функции внутри класса (`inline`, встроенный метод):**

```cpp
struct Point
{
    int x;
    int y;
    bool Visible();

    int GetX() { return x; }
    int GetY() { return y; }
};
```

Такая форма определения используется для маленьких функций (в конспекте: «встроенный метод используется, когда функция не имеет аргументов»).

**Способ 2 — объявление функции внутри класса с последующим определением вне класса:**

При втором способе метод просто объявляется внутри класса, а определение метода выполняется в произвольном месте программы, вне тела объявления класса.

```cpp
struct Point
{
    int x;
    int y;
    bool Visible();

    int GetX();
    void SetX(int newX);
};

// реализация методов
int Point::GetX()
{
    return x;
}

void Point::SetX(int NewX)
{
    x = NewX;
}
```

### 3.2. Операция `::`

`::` — операция разрешения области видимости: она указывает компилятору, какому классу принадлежит метод.

Так как рядом может быть ещё функция `GetX`, принадлежащая другим классам, требуется явно указать имя класса полностью.

Если бы `GetX` была не методом, а обычной функцией, она бы выглядела так:

```cpp
int GetX() { return x; }
```

Вызов метода у объекта и через указатель:

```cpp
APoint.GetX();
Point *pPoint = &APoint;
pPoint->GetX();
```

## 4. Управление доступом к элементам класса

Несмотря на то, что конструкция `struct` в C++ обеспечивает связь между элементами данных и методами, она всё же не очень надёжна.

Доступ к элементам данных и методам является открытым для всех, то есть `public` по умолчанию, и любой оператор из программы может читать или менять элементы данных класса типа `struct`. Возникает проблема управления доступом к элементам.

Три ключевых слова определяют правила доступа к элементам класса: `public`, `private`, `protected`. Соответствующее ключевое слово, сопровождаемое `:`, располагается перед объявлениями элементов класса.

- **`private`** — элементы, стоящие за этим словом, доступны только методам, объявленным внутри класса. По наследству доступ не передаётся, снаружи до них не добраться.
- **`protected`** — элементы, стоящие за этим словом, доступны только методам, объявленным внутри класса, и методам потомков. Снаружи до них не добраться.
- **`public`** — элементы, стоящие за этим словом, доступны из любой точки программы, имеющей ту же область действия, что и определение класса. Область действия — от места объявления до конца.

Элементы дополнительно могут иметь описание **`static`**. Элемент класса с описанием `static` будет общим для всех объектов данного класса.

### 4.1. `struct` с модификаторами и `class`

Класс типа `struct` является `public` по умолчанию, поэтому для объявления некоторой части его элементов частными (т.е. закрытыми) используется ключевое слово `private`. Все элементы после этого, которые необходимо сделать общедоступными, помечаются `public`.

```cpp
struct Point
{
private:
    int x;
    int y;
    bool Visible;
public:
    int GetX();
    void SetX(int newX);
};
```

```cpp
class Point
{ // private по умолчанию
    int x;
    int y;
    bool Visible;
public:
    int GetX();
    void SetX(int newX);
};
```

> Единственным различием между `struct` и `class` являются правила доступа, используемые по умолчанию.
> По факту программисты на C++ используют `class` с явным указанием модификаторов доступа.

### 4.2. Хороший стиль

- Хорошим стилем программирования является **сокрытие данных** — во избежание несанкционированного изменения информации и для сохранения её ценности.
- Общее правило: закрыть прямой доступ к данным и дать возможность доступа к ним только через методы этого класса.
- В C++ хорошим стилем является **априорное объявление всех элементов как приватных** с последующим тщательным отбором общедоступных элементов. Такими свойствами обладает конструкция `class` в отличие от `struct`.

## 5. Конструкторы и деструкторы: постановка задачи

Существуют специальные функции, получившие названия **конструкторов** и **деструкторов**, которые зарезервированы за каждым классом.

Стандартной проблемой при создании объектов является их **инициализация** — подробно в [лекция 3](lecture-3.md).

## 6. Выводы

- Объект — экземпляр класса; данные класса — то, что он знает, методы — то, что он делает с данными.
- Метод можно определить внутри класса (встроенный) или объявить внутри, а определить снаружи через `Класс::метод`.
- `private` / `protected` / `public` задают доступ; `static` делает элемент общим для всех объектов класса.
- `struct` и `class` отличаются только доступом по умолчанию. Хороший стиль — всё закрыть, открыть только нужное, работать с данными через методы.
