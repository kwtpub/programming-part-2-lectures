Источник: рукописный конспект, фото 4–7 (`Материалы/photo_2026-09-21 22.06.01` … `22.06.04`); в тетради подписано «ЛК4 // 09.09.26».
Продолжение [лекция 2](lecture-2.md) — там поставлена задача: как правильно инициализировать объект класса.

## 1. Проблема инициализации объекта

Рассмотрим описание и объявление:

```cpp
struct SPoint
{
public:
    int X;
    int Y;
    bool Visible;

    int GetX();
};

class CPoint
{
private:
    int X;
    int Y;
    bool Visible;
public:
    int GetX();
};

SPoint SP = {10, 20, false};
CPoint CP = {10, 20, false}; // ошибка
```

Причина, по которой нельзя инициализировать `CP`, — его поля имеют статус `private` и напрямую из программы недоступны. Доступ возможен только через методы.

Рассмотрим инициализацию полей объекта вручную:

```cpp
SPoint SP1;
SP1.X = 17;
SP1.Y = 42;
SP1.Visible = false;
```

Такой способ обеспечивает начальную установку только одного конкретного объекта `SP1`. Если будут `SP2`, `SP3`, `SP4`, …, то придётся повторять указанные действия соответствующее число раз.

## 2. Инициализирующая функция

Естественным выходом является создание инициализирующей функции, которая годится для любого объекта `SPoint`:

```cpp
void InitSPoint(SPoint *pSP, int InitX, int InitY)
{
    pSP->X = InitX;
    pSP->Y = InitY;
    pSP->Visible = false;
}
```

Эта функция берёт указатель на объект `SPoint` и использует его для доступа к элементам заданного объекта.

Функция `InitSPoint` специально разработана именно для обслуживания структуры `SPoint`. Не проще ли тогда функцию инициализации сделать встроенной — то есть `InitSPoint` надо сделать **методом**, который будет инициализировать любой объект типа `SPoint`. Такой метод называют **конструктором**.

## 3. Конструктор

**Конструктор** вызывается при создании нового объекта данного класса, т.е. когда под него отводится память и когда она инициализируется.

- Имя конструктора **совпадает с именем класса**. Именно таким путём компилятор узнаёт, что имеет дело с конструктором.
- Конструктор, как и другая функция, может иметь аргументы (`InitX`, `InitY`).
- Тело конструктора строится так же, как и тело любого другого метода, поэтому конструктор может обращаться к любому методу и любому элементу класса.
- Отличительная черта конструктора: он **не возвращает никакого значения, даже `void`**.
- Конструкторов в классе может быть **несколько**.
- Программист не обязан писать код, вызывающий конструктор класса, — всю работу за него делает компилятор.

```cpp
class CPoint
{
private:
    int X;
    int Y;
    bool Visible;
public:
    CPoint(int InitX, int InitY);
    int GetX();
};

// определение конструктора вне класса
CPoint::CPoint(int InitX, int InitY)
{
    X = InitX;
    Y = InitY;
    Visible = false;
    cout << "Constructor CPoint \n";
}

int CPoint::GetX() { return X; }
```

Создание объекта:

```cpp
CPoint CPa(10, 50); // X = 10, Y = 50
```

Значение аргумента, заданное по умолчанию:

```cpp
CPoint(int InitX, int InitY = 20);

CPoint CPb(30);     // X = 30, Y = 20
```

## 4. Деструктор

**Деструкторы** уничтожают объекты класса, предварительно созданные конструкторами, путём очистки значений и освобождения памяти.

- Деструктор имеет имя, совпадающее с именем класса, но впереди стоит знак **тильды** `~`.
- В отличие от конструктора, деструктор **не может иметь параметров**.
- Деструктор не имеет типа и ничего не возвращает.
- Объявляется среди методов класса, как правило, после конструктора: `~CPoint()`.
- Деструктор в классе **всего один**, т.е. он не может быть перегружен. Но деструкторы могут быть **виртуальными**.
- Момент вызова деструктора выбирает сам компилятор, поэтому программный код **не должен содержать явных обращений к деструктору**.
- Деструктор вызывается автоматически при выходе из блока программного кода, в котором объект был определён.
- В случае отсутствия своего деструктора сработает деструктор, заданный по умолчанию.

```cpp
CPoint::~CPoint() {} // пустое тело — если объект только инициализировался, можно так

CPoint::~CPoint()
{
    cout << "Destructor CPoint \n";
}
```

## 5. Пример: Ex05-01.cpp

```cpp
// Ex05-01.cpp
#include <iostream>
using namespace std;

// типы данных
class Point
{
private:
    int X;
    int Y;
public:
    Point(int InitX, int InitY) // конструктор определён внутри класса
    {
        X = InitX;
        Y = InitY;
        cout << "Constructor Point \n";
    } // Point()

    int GetX() { return X; }

    void SetX(int NewX)
    {
        X = NewX;
    } // SetX()

    ~Point(); // деструктор объявлен внутри класса
}; // class Point

// реализация вне класса
Point::~Point()
{
    cout << "Destructor Point \n";
} // ~Point()

// основная программа
int main()
{
    int MyX, MyY;
    cout << "Enter X = ";
    cin >> MyX;
    cout << "Enter Y = ";
    cin >> MyY;

    Point MyPoint(MyX, MyY);            // вызов конструктора
    // Point MyPoint = Point(MyX, MyY); // эквивалентная запись

    Point *pP;
    // cout << "/MyPoint X = " << MyPoint.X << endl;   // ERROR: X — private
    cout << "/MyPoint X = " << MyPoint.GetX() << endl;

    pP = &MyPoint;
    cout << "/pP->MyPoint X = " << pP->GetX() << endl;

    Point MPoint(MyX + 10, MyY + 20);
    cout << "/MPoint X = " << MPoint.GetX() << endl;

    // ~MyPoint(); // явно деструктор не вызываем
    return 0;
} // main()
```

Что показывает пример:

- `MyPoint.X` не компилируется — поле закрыто, доступ только через `GetX()`.
- Через указатель на объект методы вызываются оператором `->`.
- Деструкторы `MPoint` и `MyPoint` вызовутся сами при выходе из `main()`, в обратном порядке создания (вывод программы показан в начале [лекция 4](lecture-4.md)).

## 6. Выводы

- Закрытые поля нельзя инициализировать списком `{...}` и напрямую — нужен метод.
- Конструктор = метод с именем класса без возвращаемого значения; вызывается компилятором при создании объекта; их может быть несколько, у аргументов могут быть значения по умолчанию.
- Деструктор `~Класс()` — один, без параметров и типа, вызывается автоматически при выходе из блока; явно не вызывается; может быть виртуальным.
